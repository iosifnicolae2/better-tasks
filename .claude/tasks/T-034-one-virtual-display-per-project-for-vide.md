## Goal
User's words: "when recording in a virtual display to have one for each project and make sure that it's used one by one by the project".
So: the before/after video recording (the virtual display teammates record on) gets its own virtual display per project, so two projects never share or fight over one. Within a project, recordings take turns: one recording at a time on that display (a lock/queue), the next waits until the current one finishes, and a crashed recording doesn't leave it blocked forever.
Done: two projects can record at the same time, each on its own display; two recordings in the same project run one after the other, not on top of each other.
